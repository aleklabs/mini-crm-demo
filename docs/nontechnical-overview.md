# Mini CRM: как работает система

Mini CRM помогает строительной компании вести объекты и связанные с ними задачи в одном месте. Постановщик создаёт объект, указывает адрес, добавляет задачи и назначает исполнителя. Он видит общую картину по активным объектам, может уточнять данные и логически удалять больше не нужные записи, не уничтожая накопленную информацию.

Исполнитель видит только назначенные ему задачи и только те объекты, к которым эти задачи относятся. Он берёт задачу в работу и отправляет её на проверку. Постановщик принимает результат либо возвращает его на доработку с обязательным комментарием. После доработки исполнитель снова продолжает работу и повторно отправляет результат на проверку.

Для каждой задачи сохраняется последовательная история: кто и когда создал задачу, кто изменил её состояние, каким было предыдущее и новое состояние и какой комментарий был оставлен. Обычные пользователи не могут переписать или удалить эту историю. Состояние задачи также нельзя произвольно заменить: система разрешает только предусмотренные шаги процесса и проверяет роль участника.

Разделение доступа действует на уровне базы данных, а не только на уровне кнопок в интерфейсе. Поэтому исполнитель не сможет получить чужую задачу прямым запросом или по известной ссылке. Учётные записи создаются администратором; самостоятельная регистрация в демонстрационной системе отключена.
